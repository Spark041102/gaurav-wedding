# Gaurav & Dnyaneshwari — Wedding Invitation

An interactive, mobile-first Indian wedding invitation website for **Gaurav Jagtap & Dnyaneshwari Dhaktode**.

## Included Files
- `index.html` — Main website markup with Open Graph meta tags and favicon links.
- `css/` — Styles and animations for 3D envelope unfolding, scratch card, and floating petals.
- `js/` — Interactive logic and isolated data (`js/wedding-data.js`).
- `assets1/` — High-resolution artwork, royal GD monogram favicons, and soundtrack (`vaaroon.m4a`).

## How to Customize
1. Open `js/wedding-data.js` to change any text, dates, venues, or timings.
2. Put your couple photos in `assets1/couple-1.jpg`, `couple-2.jpg`, `couple-3.jpg`, and `couple-4.jpg`.

## Free Hosting with GitHub Pages
1. Upload this repository to GitHub.
2. Go to **Settings** > **Pages**.
3. Under **Branch**, select `main` and folder `/ (root)`, then click **Save**.
